# One line an id: `<space> <id> <live|retired> <key>`. A new id takes the next
# number of its space and is appended. An id is never renumbered or reused,
# and never changes what it names; one that leaves the game is marked
# `retired` and stays retired.
#
# The key is Dota's internal name of what the id names, the name every Dota
# data file and asset knows it by: `item_flask`, `npc_dota_hero_nevermore`,
# `nevermore_shadowraze1`, `npc_dota_neutral_kobold`, and for an effect the
# modifier it is (`modifier_flask_healing`). An effect Dota has no modifier
# for takes a `bota_` key. The keys replaced English display names once
# (2026-10-30), with every id keeping its meaning: a key is never renamed
# again.
